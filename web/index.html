The same data moves through every stage below on every run. Bar width is roughly how large each stage's feature dimension is, log-scaled — watch how much it jumps at the LM head, where the hidden size expands out to the full vocabulary.
#
Token IDs
Each token is just an integer — an index into the vocabulary.
→
Token embeddings
Each integer is looked up in the embedding matrix and becomes a real-valued vector.
‖·‖
Final RMSNorm
Root Mean Square Normalization (RMSNorm) gives every value one final rescale by its root mean square, so everything lands in a consistent range right before the model makes its prediction
Wᵀ
LM head
One learned projection turns each token's hidden vector into a raw compatibility score against every word in the vocabulary.
Σ
Softmax
Those raw scores become a probability distribution over the whole vocabulary — one number per word, all adding up to 1.
